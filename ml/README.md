# ML: прогноз загрузки трамвайных маршрутов

Почасовой прогноз посадок по маршрутам на 2025-11-01 .. 2025-12-31. WAPE-score на закрытом тесте **0.88359**.

## Запуск

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r ml/requirements.txt
python -m ml.predict path/to/dataset.zip      # по умолчанию ml/data/dataset.zip
```

Результат: `ml/output/submission.csv` (`route;date;hour;prediction`, 14 640 строк). CPU, около 5 минут.

## Структура

| Файл | Что делает |
|---|---|
| `parsing.py` | `load_external_data` — календарь и погода по дням (кэш в `ml/data/external/`) |
| `preprocessing.py` | `load_dataset` — посадки из `dataset.zip`; `build_day_features` — признаки дня, школьные каникулы |
| `predict.py` | класс `TramForecaster` (модель и ансамбль, `predict(days)`) и `main` — запись ответа |

## Модель

Прогноз — среднее трёх частей, все модели zero-shot (`amazon/chronos-2`, без обучения на наших данных):

1. **RH** — Chronos-2 по 216 суточным рядам «маршрут × час», горизонт 61 день.
2. **RHD** — то же + тип дня.
3. **V2** — среднее четырёх прогнозов суточного уровня, разложенных по часам формой недельного профиля:
   профиль; Chronos-2 по суточным суммам без ковариат; с календарём; с календарём и погодой.
   29–30 декабря × 0.90 (уровень первых рабочих дней после Нового года, 9–10 января).

Маршрут 5 в данных не имеет посадок → 0.

## Ковариаты (известны на весь горизонт прогноза)

| Ковариата | Смысл | Где используется |
|---|---|---|
| `day_off` | нерабочий день | RH, RHD, суточные модели |
| `holiday` | нерабочий будний день (праздник, перенос) | RH, RHD, суточные модели |
| `shortened` | сокращённый предпраздничный день | RH, RHD |
| `school_quarters`, `school_modular` | школьные каникулы Москвы (четверти / модули, с летом) | RH, RHD |
| `day_type` | будни / сб / вс / праздник / рабочий выходной / перед / после праздников | RHD |
| `dow` | день недели | суточные модели |
| `precipitation_sum`, `snowfall_sum`, `temperature_2m_mean` | фактическая погода | одна суточная модель |
