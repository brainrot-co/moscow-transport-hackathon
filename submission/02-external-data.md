# 2. Внешние данные

Все файлы лежат в [`dataset/external/`](../dataset/external/) и воспроизводятся скриптами из [`ml/scripts/`](../ml/scripts/). Эффект каждого источника проверен бэктестом Chronos-2 «маршрут × час» на двух окнах по 61 дню: история до 21.04 → прогноз 21.04–20.06 и история до 01.09 → прогноз 01.09–31.10. Все запуски записаны в MLflow.

## Календарь и праздники

Подтверждён эффектом сильнее всего. Весеннее окно захватывает майские праздники, поэтому там прирост +0.068. На горизонте ноября–декабря модель закладывает по календарю:

| день | эффект праздника (контрольный прогон без фактора) |
|---|---|
| 01.11, рабочая сокращённая суббота | +63% к обычной субботе |
| 03.11, 04.11, праздники | −56%, −55% |
| 31.12 | −52% |

Календарь на 2026 год нужен и краткосрочному прогнозу (с середины ноября он заходит в 2026), и годовому.

## Школьные каникулы

Дают «учебный режим»: осенью модель без каникул не понимает, что сентябрь выше августа. На весеннем окне эффект слабо отрицательный: летний провал частично объясняется ещё и месяцем. Даты рекомендованные, отдельные школы могут отступать. Каникул 2026/27 учебного года в справочнике пока нет.

## Погода

В модель не вошла, и это осознанное решение:

1. На бэктесте фактическая погода как признак ухудшает прогноз на 0.003–0.006.
2. В эксплуатации на горизонте 61 день фактической погоды нет, есть только прогноз погоды на 1–2 недели.
3. Эффект погоды на трамвай мал: по исследованиям −4% в дни с сильным дождём.

Погода учитывается **поправкой** в интерфейсе: диспетчер ставит «сильный дождь» (×0.96), «снегопад» (×0.95) или «экстремальный снегопад» (×0.70) на весь город и сразу видит изменение прогноза. Значения взяты из исследований и сверены с нашей историей: в часы с дождём 0.5–2 мм/ч посадок меньше на 4.7% [−6.6%; −3.0%] по 49 часам. Источники: [docs/correction-factors-sources.md](../docs/correction-factors-sources.md).

## События

KudaGo проверен как признак «событие в радиусе 800 м от остановки»: эффекта нет. Причина в данных: в 2025 году рядом с трамвайными остановками почти одни детские театры, библиотеки и кинотеатры, ни одного крупного концерта или матча.

Событие учитывается **поправкой** на маршруты: «крупное мероприятие» ×1.2 по исследованию Lepage & Morency (2021, Монреаль). Ремонты и закрытия — поправки «маршрут укорочен» ×0.45 и «маршрут не ходит» ×0. Значение для укорочения оценено по нашей истории: медиана по 18 дням сбоев на 4 маршрутах.

## Дорожный трафик

Не используется: открытого исторического источника загруженности улиц Москвы с почасовой детализацией за 2025 год не нашли. Трамвай в основном идёт по обособленному полотну, поэтому зависит от пробок меньше автобуса.

## Как обновить

```bash
uv run python ml/scripts/fetch_covariates.py      # календарь isDayOff + погода Open-Meteo
uv run python ml/scripts/fetch_osm_routes.py      # линии из OSM
uv run python ml/scripts/build_route_stops.py     # остановки: справочник + OSM
```

Календарь и каникулы сейчас копируются в образ воркера. После обновления нужна пересборка: `make prod-restart`.
