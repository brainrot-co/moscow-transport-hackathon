# артефакты, код обучения и инференса, запуск для ML-контура

## Задача

Мы предсказываем число посадок на маршруте трамвая за час.
Дано 10 маршрутов: 1, 5, 7, 11, 12, 17, 25, 26, 28, 50. История за январь–октябрь 2025 года, прогнозируем от заданной даты и далее.

## Результат

| что | WAPE-score |
|---|---|
| лидерборд, ноябрь–декабрь 2025 (лучший сабмит, ансамбль) | **0.88359** |
| лидерборд, одиночный Chronos-2 `cal_school_daytype` | 0.87989 |
| baseline организаторов | ≈ 0.48 |
| бэктест сен–окт 2025, 61 день (одиночный Chronos-2 с календарём и каникулами) | 0.885 |
| бэктест апр–июнь 2025, 61 день (то же) | 0.871 |
| реальная точность опубликованных прогонов (прогнозы от 01.09, 15.09, 01.10, 15.10, факт до 01.11) | 0.885–0.904 |
| годовой прогноз, бэктесты на 2–6 месяцев | 0.787–0.853 |

## Модель

ML-контур даёт прогноз двумя моделями: краткосрочной на 61 день вперёд (из неё берутся прогнозы на день по часам, неделю и месяц) и годовой до 365 дней. Бэкенд склеивает их с фактом в один ряд:

```
факт (до водяного знака) → краткосрочный прогноз (61 день) → годовой прогноз (до 365 дней)
```

### Краткосрочный прогноз (день, неделя, месяц): ансамбль на Chronos-2

[amazon/chronos-2](https://huggingface.co/amazon/chronos-2) — предобученная foundation-модель для временных рядов (120M параметров). Используется **zero-shot**: на наших данных не дообучается, получает историю и ковариаты в контексте. Дообучение LoRA пробовали, на 10 месяцах истории оно переобучается.

Итоговая архитектура - это ансамбль из трёх участников, прогноз — среднее:

| участник | как устроен |
|---|---|
| RH | Chronos-2, каждая пара маршрут-час является отдельным суточным рядом (9 × 24 = 216 рядов), ковариаты (события, влияющие на прогноз): производственный календарь + школьные каникулы |
| RHD | то же + тип дня (будни, сб, вс, праздник, рабочий выходной, пред- и послепраздничный) |
| V2 | прогноз суточной суммы маршрута (среднее недельного профиля и Chronos-2 по дневным суммам без ковариат и с календарём), раскладка по часам долями суточного профиля |

В сабмите 0.88359 у V2 был ещё один вариант с фактической погодой ноября–декабря из архива, то есть с идеальным прогнозом погоды, что является по сути ликом. В сервисе прогноза погоды нет, поэтому модель по умолчанию (`ensemble_cal_school_daytype_profile`) погоду не использует. Вариант с погодой доступен как `ensemble_cal_school_daytype_profile_wx`.

Квантили q10 и q90 — из Chronos-2, среднее по участникам, у которых они есть.

Схема ансамбля: [ensemble.svg](ensemble.svg). Как выбирали модель — в разделе [«Эксперименты»](#эксперименты).

### Годовой прогноз: сезонная регрессия

Chronos используется только на горизонте 61 день. На год строится объяснимой моделью, отдельно по каждому маршруту:

```
log(1 + дневная сумма) = уровень + эффект месяца + эффект типа дня + эффект каникул
```

Коэффициенты оцениваются обычным МНК. В обучение идут только дни со статусом `final` без флага `anomaly`: неполные дни и дни ремонтов не описывают обычный режим маршрута. Логарифм делает эффекты процентными и перемножаемыми, поэтому прогноз не бывает отрицательным. Тренд год к году по одному году истории не оценить, поэтому уровень подтягивается к последним 8 неделям: к нему прибавляется средний остаток модели за этот период. Месяцы без истории берут эффект последнего наблюдённого месяца. Дневная сумма раскладывается по часам суточным профилем маршрута за последние 8 недель, отдельно для рабочего дня, субботы и выходного или праздника.

### Эффекты для поправочных коэффициентов

После основного прогноза воркер делает контрольные прогоны той же моделью с «выключенным» фактором на горизонте: праздники становятся обычными днями, каникулы обнуляются. Разница пишется в `effects.parquet`. Слайдер в интерфейсе масштабирует этот эффект: `yhat × exp(log_effect × (k − 1))`.

## Эксперименты

Бэктесты краткосрочной модели, по которым выбран ансамбль. Колонка «Тест» — WAPE-score на лидерборде (ноябрь–декабрь 2025).

### Валидация

4 периода, каждый повторяет задачу: история до даты X → почасовой прогноз вперёд
(апр–май, май–июнь, сен–окт — по 61 день; окт — 31 день). Метрика выбора — средний WAPE-score.
Для итоговых моделей валидация предсказывала закрытый тест с точностью ±0.001–0.002.

Потолок подхода: при **идеально известных суточных суммах** и раскладке профилем — 0.909 (окт 0.925).
Остаток ошибки — шум отдельных часов.

## Артефакты

| артефакт | где |
|---|---|
| веса Chronos-2 | скачиваются с Hugging Face при сборке образа воркера и запекаются в него (`/opt/hf`, `HF_HUB_OFFLINE=1`). При работе сеть не нужна |
| стартовый прогноз (факты + пара прогонов short/year + справочники) | [`ml/seed/`](../../ml/seed/), запечён в образ ingest |
| формат прогона | `runs/<run_id>/forecasts.parquet` (`route, ts, yhat, q10, q90`), `effects.parquet`, `meta.json` (модель, данные, проверки качества, маршруты без истории) |
| сабмиты на лидерборд | `ml/artifacts/runs/submission_*/` (`submission.csv`, `preds.parquet`, `summary.json`) |
| журнал экспериментов | MLflow (`ml/mlflow/`, локально): параметры, окна бэктеста, метрики по каждому запуску |
