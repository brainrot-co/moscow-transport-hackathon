## Календарь и праздники

Подтверждён эффектом сильнее всего. Весеннее окно захватывает майские праздники, поэтому там прирост +0.068. На горизонте ноября–декабря модель закладывает по календарю:

| день | эффект праздника (контрольный прогон без фактора) |
|---|---|
| 01.11, рабочая сокращённая суббота | +63% к обычной субботе |
| 03.11, 04.11, праздники | −56%, −55% |
| 31.12 | −52% |

Календарь на 2026 год нужен и краткосрочному прогнозу (с середины ноября он заходит в 2026), и годовому.

## Школьные каникулы

Дают учебный режим: осенью модель без каникул не понимает, что сентябрь выше августа. На весеннем окне эффект слабо отрицательный: летний провал частично объясняется ещё и месяцем. Даты рекомендованные, отдельные школы могут отступать.

## Погода

В модель не вошла: на бэктесте с погодой скор даже немного падал, на 0.003 весной (0.877 → 0.874) и на 0.006 осенью (0.861 → 0.855).

Погода учитывается **поправкой** в интерфейсе: диспетчер ставит "сильный дождь" (×0.96), "снегопад" (×0.95) или "экстремальный снегопад" (×0.70) на весь город и сразу видит изменение прогноза. Значения взяты из исследований и сверены с нашей историей: в часы с дождём 0.5–2 мм/ч посадок меньше на 4.7% [−6.6%; −3.0%] по 49 часам.

## События

KudaGo проверен как признак «событие в радиусе 800 м от остановки»: эффекта нет.

## Дорожный трафик

Трамвай в основном идёт по обособленному полотну, поэтому зависит от пробок меньше автобуса, так что не используется.

## Как обновить

```bash
uv run python ml/scripts/fetch_covariates.py      # календарь isDayOff + погода Open-Meteo
uv run python ml/scripts/fetch_osm_routes.py      # линии из OSM
uv run python ml/scripts/build_route_stops.py     # остановки: справочник + OSM
```

Календарь и каникулы сейчас копируются в образ воркера. После обновления нужна пересборка: `make prod-restart`.
