## Как читать код (в этом порядке)

| файл | что там | на что смотреть |
|---|---|---|
| `ml/src/mtml/storage.py` | раскладка тома, атомарная запись | `write_atomic`: временный файл + `os.replace` |
| `ml/src/mtml/ingest/settings.py` | настройки из переменных окружения | пороги статусов, `INGEST_MEMORY_LIMIT` |
| `ml/src/mtml/ingest/reader.py` | разбор CSV в DuckDB | колонки читаются как текст и приводятся `TRY_CAST`; причины карантина в `CASE` |
| `ml/src/mtml/ingest/raw.py` | сырой слой по дням | дедупликация `QUALIFY row_number()`, прежняя строка важнее новой |
| `ml/src/mtml/ingest/actuals.py` | факты маршрут × час | затронутые дни пересчитываются целиком, а не прибавляются |
| `ml/src/mtml/ingest/status.py` | статусы дней и водяной знак | правила `final / partial / missing`, `anomaly` не понижает статус |
| `ml/src/mtml/ingest/pipeline.py` | проход одного файла, журнал, inbox | порядок шагов, обработка ошибок, перемещение файлов |
| `ml/src/mtml/ingest/__main__.py` | CLI: `load`, `once`, `run` | московское время независимо от часового пояса контейнера |
| `ml/tests/test_ingest.py` | тесты | сценарии: карантин, повторы, ночной хвост, статусы |
| `ml/scripts/check_actuals.py` | сверка с labels | приёмочная проверка |

Документы: `docs/ml-backend-contract.html` (контракт, раздел ingest обновлён), `docs/corrections-spec.html` (поправки для бэкенда и фронтенда).
